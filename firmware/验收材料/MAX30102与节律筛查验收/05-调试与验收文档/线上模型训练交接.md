# 节律模型线上训练交接

## 1. 当前可直接复用的输入

- 原始 PPG：RED、IR；
- 滤波调试量：RED/IR DC、AC、filtered IR、envelope；
- 峰值与间隔：peak candidate、beat accepted、IBI；
- 质量与输出：finger、SQI、HR、SpO₂、valid；
- 节律上下文：状态、置信度、IBI mean、SDNN、RMSSD、pNN50、beat count；
- 运动上下文：IMU 合加速度和合角速度。

串口字段定义见 `04-Qt上位机采集代码/protocol.py`，端侧特征实现见
`03-固件关键代码/VitalsProcessor.cpp`。

## 2. 固定窗口契约

- 有效 FIFO 输出率：25 Hz；
- 特征窗口：15 秒；
- 推理间隔：5 秒；
- 最少 IBI：12；
- 节律最低 SQI：0.70；
- IMU 运动后稳定等待：15 秒；
- 当前六个模型输入：IBI CV、RMSSD/mean IBI、pNN50、最大相邻 IBI 差/mean、SQI、
  心率越界分数。

## 3. 训练数据要求

必须选择带同步 ECG 参考标签的公开 PPG 节律数据。P001～P043 只作为正常负样本、
接触压力、模块运动和端侧回放集，不作为 AF 真实标签训练集。

数据必须按受试者划分训练、验证、测试集，禁止同一受试者窗口跨集合。若公开数据只支持
二分类，应明确使用“正常/AF + 独立质量门控”；若支持其他心律失常标签，再建立正常、
其他不规则、AF 三分类映射。

## 4. 建议实现顺序

1. 实现与固件一致的峰值检测和 IBI 提取；
2. 建立 Python 与 ESP32 特征黄金样本一致性测试；
3. 生成 15 秒窗口及六维特征；
4. 先训练逻辑回归/线性分类器，再评估小型 MLP；
5. 采用受试者级独立测试集；
6. 输出 INT8 权重和偏置；
7. 替换 `RhythmClassifier.cpp` 中的基线常量；
8. 使用本地 P001～P043 回放正常场景和伪影假告警；
9. 重新记录 RAM、Flash、推理平均/P95/最大耗时；
10. 独立测试通过后，才将 `RHYTHM_MODEL_CALIBRATED` 改为 `true`。

## 5. 必须交付的指标

- 受试者数、窗口数和无效窗口比例；
- 三分类混淆矩阵或明确的二分类标签映射；
- 每类 precision、recall/sensitivity、specificity、F1；
- macro-F1、balanced accuracy，条件允许时报告 AUROC；
- 连续窗口确认前后的召回率和误报率；
- 每小时假告警数；
- INT8 前后指标差异；
- ESP32 RAM、Flash、模型字节数和推理耗时。

## 6. 禁止事项

- 不得把未校准基线输出当作真实标签；
- 不得随机按窗口切分导致受试者泄漏；
- 不得为了降低误报而删除所有异常 IBI，从而抹掉真实不规则性；
- 不得在独立测试完成前设置 `model_calibrated=true`；
- 不得将本功能描述为医疗诊断。
