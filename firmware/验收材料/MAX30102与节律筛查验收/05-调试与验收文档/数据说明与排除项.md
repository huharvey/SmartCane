# 数据说明与历史标签备注

## 1. 原始数据保留原则

验收包保留 P001～P043 全部原始 CSV，没有删除表现较差、操作不完整或质量不足的文件。
`trials.csv` 保持采集时生成的原始字段和历史标签，备注只写在本文件中，不回写原始数据。

## 2. 标准仪器对照

因没有标准心率/血氧仪，本轮取消 `reference_compare` 场景。历史 `trials.csv` 仍含空的
`hr_mae`、`spo2_mae` 兼容列，不代表进行过精度对照。

## 3. 场景标签备注

- P029～P035：CSV 历史标签为 `cane_motion`，实际操作只移动 MAX30102 模块，没有移动
  IMU。该组用于 PPG 模块/接触运动伪影分析，不能作为 IMU 运动抑制重复性证据。
- P036：`action_marked=false`，可用于连续静止波形观察，不作为严格动作起点计时样本。
- P040：记录中有较长无手指或心搏不足阶段，没有形成端侧推理窗口，原文件保留。
- P043：稳定段有效率 57.8%，但 59 个有效 IBI 均位于 500～1200 ms，且形成 3 个
  `NORMAL` 窗口。该文件作为接触不连续时的安全降级样本保留。

## 4. 结果使用限制

- 本地 `NORMAL`、`IRREGULAR` 是未校准基线模型输出，不是真实医疗标签；
- 不得把压力、移动或低质量记录标成房颤正样本；
- 不得根据本数据计算房颤召回率、特异度或临床准确率；
- HR/SpO₂ 只可用于内部趋势和稳定性分析，不得宣称已经完成标准精度校准。
