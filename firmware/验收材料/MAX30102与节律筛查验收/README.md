# 智能拐杖 MAX30102 与节律筛查验收说明

## 1. 验收结论

本目录归档了 MAX30102 接入、RED/IR FIFO 原始数据采集、手指检测、滤波与峰值检测、
HR/SpO₂ 原型估算、SQI 质量门控、15 秒节律特征窗口、端侧基线分类器和 Qt 可视化采集
工具的调试材料。

本地调试共保存 43 份原始 PPG 记录、59098 个样本，总记录时长 2365.49 秒（约
39.42 分钟）。全部记录保持 25 Hz 有效 FIFO 输出率，序号丢帧为 0，FIFO 溢出为 0，
最大样本间隔为 50 ms。

峰值算法修改后的最终验收 P041～P043 共得到 243 个有效 IBI：

- 小于 500 ms 的短 IBI：0；
- 大于 1200 ms 的长 IBI：0；
- IBI 变异系数分别为 0.070、0.058、0.100；
- 共形成 29 次端侧节律推理，29 次均为 `NORMAL`；
- `IRREGULAR`、`INCONCLUSIVE`、`SUSPECTED_AF` 均为 0；
- 推理耗时平均 65.6 μs，P95 为 95.4 μs，最大 106 μs。

据此，当前实现满足课程设计/工程原型的本地 PPG 采集、质量控制和节律筛查数据链交付
要求。P043 的稳定段有效率为 57.8%，但系统在心搏不连续时主动使旧 HR 失效，没有用
陈旧值冒充有效测量，因此作为安全降级样本保留。

## 2. 结论边界

本轮没有标准心率/血氧仪，也没有 ECG 参考标签，因此：

- 不报告 HR/SpO₂ 的 MAE、Bias、RMSE 或医疗级精度；
- 当前 SpO₂ 公式仅为课程原型趋势估算；
- 当前节律权重是未校准的端侧集成基线，`model_calibrated=false`；
- 本地数据只用于正常负样本、接触压力、运动伪影和回归测试，不能当作房颤真实标签；
- 不能据此声称具有房颤诊断能力或医疗器械性能。

## 4. 最终算法修改

最终实现见 `03-固件关键代码/VitalsProcessor.cpp`：

1. 局部极大值除幅度阈值外，还必须满足相对上一谷值的突出度阈值；
2. 近期 IBI 稳定时启用有上限的自适应不应期；
3. 突出度足够强的提前心搏仍可通过，避免机械抹平真实不规则性；
4. HR 显示使用最近 IBI 中位数，节律特征仍使用未平滑的有效 IBI 序列；
5. 长间隔后清空旧 IBI 窗口，重新积累连续心搏；
6. 连续约 3 秒没有新有效心搏时，旧 HR 立即失效。
