# 跌倒确认与 MAX30102 调试

本版本在不改变现有避障、SOS、照明、GPS、相机和网页控制接口的前提下，增加了：

- `SUSPECTED_FALL`（疑似跌倒）4 秒确认状态；
- MAX30102 原始 RED/IR PPG 采样、手指检测、心率、血氧估算与信号质量；
- 网页、`/api/status` JSON、串口状态行中的新增状态。

> 心率与血氧仅用于课程项目的非医疗监测演示，不能作为医疗诊断或医疗级测量结果。

## 1. 跌倒确认流程

```text
现有 IMU 跌倒规则命中
  -> SUSPECTED_FALL（短促蜂鸣、LED 快闪）
  -> 等待 4 秒
     -> 期间按实体 SOS 键或网页“解除告警”：回到 NORMAL
     -> 未取消：转为锁存 FALL，沿用原有持续报警/相机事件行为
```

`SUSPECTED_FALL` 不会使用 `delay()` 阻塞系统，摄像头、GPS、避障和 Wi-Fi 会继续运行。
取消后，跌倒检测有 3 秒冷却时间，避免同一次动作立即重复触发。

### 测试

1. 上传固件，打开串口监视器（115200）。
2. 在软垫或安全环境下对拐杖进行受控倾倒测试；不要让人实际跌倒。
3. 出现 `SUSPECTED_FALL` 后，在 4 秒内按一次实体按键或网页“解除告警”，应回到正常。
4. 再次测试且不取消，约 4 秒后应显示 `FALL`，并保持原有蜂鸣器/LED 告警。
5. 在 `FALL` 下再次按实体按键或网页解除，应解除告警。

确认等待时间在 `src/config/UserConfig.h` 的
`SUSPECTED_FALL_CONFIRM_MS` 中设置，默认 `4000` ms。

### 高频标定数据

正式阈值标定不要使用 5 Hz `SC1 TEL` 峰值。Qt 上位机的高频采集区会按实际收到的
每个新 JY901S 样本保存 CSV，记录原始九轴、A/G/Tilt、候选阶段和告警结果。
每次先记录 5 秒直立基线，点击“动作开始”，完成动作后再保留 5 秒尾段。

采集目录中的 `trials.csv` 自动将模拟跌倒分为 TP/FN、正常动作分为 FP/TN，并显示：

```text
召回率 = TP / (TP + FN)
误报率 = FP / (FP + TN)
```

正常动作进入 `SUSPECTED_FALL` 即计为误报。必须分开标定集和验证集，只有独立
验证数据稳定后才能冻结 `UserConfig.h` 中的跌倒阈值。

## 2. MAX30102 接线

MAX30102 与现有 I2C 超声波都使用地址 `0x57`，不能接到现有 GPIO41/42 总线。
本工程将 MAX30102 放在第二路 I2C：

| MAX30102 模块 | ESP32-S3-CAM | 说明 |
|---|---:|---|
| VCC / VIN | 3V3 | 仅在模块明确支持 3.3 V 供电时这样连接；不要把裸芯片直接接到 3.3 V。 |
| GND | GND | 必须共地。 |
| SDA | GPIO2（板上 G2） | 第二路 I2C 数据线。 |
| SCL | GPIO48（板上 G48） | 第二路 I2C 时钟线。GPIO48 的板载 RGB 不再单独使用。 |
| INT | 不接 | 当前采用 FIFO 轮询，不需要中断线。 |

不要把 MAX30102 的 SDA/SCL 接到现有 GPIO41/42；那会与 `0x57` 超声波冲突。
MAX30102 模块的 I2C 上拉必须是 3.3 V 电平。

## 3. MAX30102 上电测试

上传后，串口启动日志应出现：

```text
[MAX30102] online on I2C1 SDA=2 SCL=48
```

若没有接模块，会出现 `not found`，随后每 5 秒重试一次；这不会影响其他已实现功能。

正常状态行示例：

```text
[State] NORMAL ... max30102=ok finger=yes hr=76.0 spo2=98.0 sq=0.82 ...
```

网页会增加三张卡片：心率、血氧、PPG。

- `模块离线`：检查 VCC、GND、GPIO2/GPIO48、SDA/SCL 是否接反。
- `请放置手指`：模块在线，但 IR 值未达到手指接触初始阈值。
- `信号采集`：已检测到手指，但仍在积累约 4 秒波形或质量不足。
- 显示百分比：表示信号质量；绿色时才同时显示心率和血氧估算值。

测试时用手指轻压传感器，保持不动至少 8～12 秒，并避免强环境光直射。走路、松动、手指过冷或模块光学结构不佳都会使读数无效。

## 4. 初始参数位置

均在 `src/config/UserConfig.h`：

- `MAX30102_FINGER_IR_THRESHOLD`：手指存在阈值，默认 `50000`；若始终显示“请放置手指”，可根据串口 raw IR 数据适当降低。
- `MAX30102_LED_CURRENT`：RED/IR LED 初始驱动电流。
- `MAX30102_VALID_QUALITY_MIN`：网页允许显示正式估算值的最低信号质量。
- `MAX30102_SPO2_WINDOW_MS`：血氧计算窗口，默认 4 秒。

建议一次只改一个参数，上传后记录稳定静止数据，再决定是否保留修改。
